# 🔍 查询复盘项目功能说明

## ✅ 新增功能

已在"复盘项目列表"页面添加查询功能，支持：

### 1. 按复盘日期段查询
- **开始日期**：选择查询的起始日期
- **结束日期**：选择查询的结束日期
- 支持只选开始日期（查询该日期之后的所有项目）
- 支持只选结束日期（查询该日期之前的所有项目）
- 支持同时选择起止日期（查询日期范围内的项目）

### 2. 按项目名称关键词查询
- 支持输入关键词模糊匹配
- 可匹配：项目名称、企业名称、项目编码
- 不区分大小写
- 支持部分匹配（如输入"乒乓球"可匹配"乒乓球项目复盘"）

---

## 📱 使用步骤

### 步骤1：进入项目列表页面
1. 打开应用
2. 点击"项目列表"或侧边栏的"📁 项目列表"

### 步骤2：设置查询条件
在页面上方的查询区域：

**按日期查询：**
- 点击"开始日期"选择起始日期
- 点击"结束日期"选择结束日期
- 可同时设置或只设置其中一个

**按关键词查询：**
- 在"项目名称关键词"输入框中输入关键词
- 支持模糊搜索

### 步骤3：执行查询
点击蓝色的 **"查询"** 按钮

系统会显示符合所有条件的结果数量

### 步骤4：查看结果
- 查询结果会显示在项目列表区域
- 点击任意项目卡片可查看详情

### 步骤5：重置查询
点击灰色的 **"重置条件"** 按钮

将清空所有查询条件，显示全部项目

## 💡 使用技巧

### 1. 快速查找
- 如果只输入关键词，不选日期，可查找所有历史项目
- 关键词支持部分匹配，输入"乒乓"也能找到"乒乓球项目"

### 2. 精确日期查询
- 开始日期和结束日期选择同一天，可查询特定某天的项目
- 例如：开始日期=2024-02-10，结束日期=2024-02-10

### 3. 查看全部项目
- 点击"重置条件"按钮，或清空所有条件后点击"查询"
- 将显示所有复盘项目

### 4. 结果为空时
- 如果查询结果为空，会显示"暂无复盘项目"
- 可点击"创建第一个项目"新建项目
- 或调整查询条件后重新查询

## 🔧 技术实现

### 查询逻辑
```javascript
// 1. 按日期段筛选
if (startDate || endDate) {
  projects = projects.filter(project => {
    const projectDate = new Date(project.review_date);
    // 检查项目日期是否在范围内
  });
}

// 2. 按关键词筛选
if (keyword) {
  projects = projects.filter(project => {
    return project.name?.includes(keyword) ||
           project.enterprise?.includes(keyword) ||
           project.project_code?.includes(keyword);
  });
}
```

### 支持的匹配字段
- ✅ 项目名称 (`project.name`)
- ✅ 企业名称 (`project.enterprise`)
- ✅ 项目编码 (`project.project_code`)

## 📋 注意事项

1. **日期格式**：使用YYYY-MM-DD格式（如：2024-01-15）

2. **关键词大小写**：不区分大小写，输入"Project"可匹配"project"或"PROJECT"

3. **空值处理**：
   - 如果项目未设置复盘日期，日期查询时会被过滤掉
   - 如果项目未设置名称/企业/编码，关键词查询时不会被匹配

4. **性能优化**：
   - 查询在本地执行，响应速度快
   - 支持大量项目数据的快速筛选

5. **查询结果排序**：
   - 查询结果按更新时间倒序排列
   - 最新更新的项目显示在最前面

## 📞 常见问题

### Q1: 为什么查询不到项目？
**A:** 可能原因：
- 日期范围设置不正确（检查起止日期）
- 关键词拼写错误
- 项目确实不存在符合条件的记录
- 建议先点击"重置条件"查看所有项目

### Q2: 可以按企业名称查询吗？
**A:** 可以！在关键词输入框中输入企业名称即可，系统会同时搜索项目名称、企业和编码。

### Q3: 查询速度如何？
**A:** 非常快！因为所有数据存储在本地（localStorage），查询在设备本地执行，无需网络请求。

### Q4: 可以保存常用的查询条件吗？
**A:** 当前版本暂不支持，但可在后续版本中考虑添加"保存查询方案"功能。
